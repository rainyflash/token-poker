# Code of Conduct

We value direct technical criticism and honest conclusions. We do not accept turning technical disagreement into personal abuse.

## Expected behavior

- Critique code, protocols, evidence, and risk rather than contributors.
- Clearly separate verified facts, reasonable inferences, and personal preferences.
- Respect differences in experience, language, identity, and accessibility needs.
- Report security issues privately before discussing exploitable details in public.
- Accept that maintainers may reject changes to protect users, protocol compatibility, or architectural boundaries.

## Unacceptable behavior

- Harassment, discrimination, threats, stalking, doxxing, or publishing another person's identity without permission.
- Sexualized content, insults, incitement, or deliberate disruption.
- Posting keys, authentication material, private user data, or live exploit details in issues, logs, or test data.
- Fabricating test results, security guarantees, project affiliations, or evidence to win an argument.

## Enforcement

Maintainers may edit or remove violating content, reject contributions, or temporarily or permanently restrict participation. Report conduct issues through a private maintainer channel. Security vulnerabilities must follow `SECURITY.md`. Maintainers will minimize disclosure of reports and recuse themselves from conflicts of interest whenever possible.
